3. Напиши тесты 
   Опиши необходимые локаторы с помощью Page Object. Создай отдельный пакет для Page Object. Для каждой страницы нужно создать отдельный класс с Page Object. Напиши тесты на Selenium. Тесты нужно разделить по тематике или функциональности. Обрати внимание: не нужно создавать отдельный класс для каждого теста. Добавь тесты на одну функциональность в один класс. Все тесты должны лежать в директории test. Проверь, что тесты запускаются.
4. В функционале есть баги, тесты должны соответствовать ТЗ, поэтому тесты, выявляющие баги, должны падать при прогоне
5. Сделай отчёт в Allure Сгенерируй Allure-отчёт и запушь его в репозиторий.
6. Как будут оценивать твою работу
- Нейминг элементов корректный.
- Для каждого блока проверок тесты лежат в отдельном классе и отдельном тестовом модуле.
- Написаны тесты на функциональность «Отрисовка маршрута».
- Написаны тесты на функциональность «Отрисовка блока с выбором маршрута».
- Написаны тесты на функциональность «Подготовка к заказу такси».
- Написаны тесты на функциональность «Заказ тарифа Такси» + полный флоу.
- Сгенерирован Allure-отчёт. В репозиторий запушена только папка с отчётом.
- Для предусловий используются фикстуры
- Все тесты независимы.
- Тестовые данные хранятся в отдельном модуле
- В тестах и объектах страниц отсутствуют локаторы элементов
- В тестах отсутствуют условия (тест должен быть всегда однозначен)
- В коде отсутствуют принты и закомменченный код
- В коде отсутствуют слипы и неявные ожидания
- В объектах страниц отсутствуют методы, для работы с элементами с других страниц
- В тестах отсутствует прямое обращение к driver (только через методы пейджей)
- Тесты с багами должны быть помечены декоратором @pytest.mark.xfail
