# Воспроизведённые дефекты

Окружение: https://qa-routes.education-services.ru/, Chrome 156, 6 ноября 2026 года.

## BUG-001 — неверное описание тарифа «Сонный»

Шаги: ввести «Хамовнический вал, 34» и «Зубовский бульвар, 37», выбрать
«Быстрый», нажать «Вызвать такси», навести на `i` тарифа «Сонный».

Ожидание по ТЗ: «Для тех, кто не выспался».
Фактически: «Если мысли не выходят из головы» — описание «Разговорчивого».

Проверка: параметр «Сонный» в `TestTaxiTariffs.test_known_incorrect_tariff_tooltip`.

## BUG-002 — неверное описание тарифа «Разговорчивый»

Шаги: открыть ту же форму и навести на `i` тарифа «Разговорчивый».

Ожидание по ТЗ: «Если мысли не выходят из головы».
Фактически: «Для тех, кто не выспался» — описание «Сонного».

Проверка: параметр «Разговорчивый» в `TestTaxiTariffs.test_known_incorrect_tariff_tooltip`.

Оба теста сохраняют ожидания ТЗ, имеют строгую метку xfail с причиной и
ограничением на AssertionError. Отчёт показывает их как пропущенные с причиной XFAIL;
`--runxfail` превращает их в обычные падения. При исправлении продукта потребуется
убрать соответствующую метку, иначе строгий XPASS завершит прогон с ошибкой.
